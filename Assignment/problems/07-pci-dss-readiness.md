# Problem 07: PCI DSS Readiness

- Strong session controls, access control, logging, masking, and transport protections are implemented in code.
- Cardholder data should never be stored without tokenization or an approved vault.
- Secrets must be rotated and injected from a secure secret manager in production.
- Quarterly ASV scans, annual penetration tests, and least-privilege access reviews should be part of deployment governance.
