# Problem 08: Security Incident Response Plan

## Detection

- Trigger alerts for repeated failed logins, untrusted devices, abnormal transfer velocity, and high-risk transaction patterns.

## Containment

- Revoke active sessions, disable risky payment actions, and isolate affected accounts or API keys.

## Eradication

- Patch the root cause, rotate credentials, invalidate tokens, and verify forensic log integrity.

## Recovery

- Restore service gradually, increase monitoring, and confirm suspicious activity has stopped.

## Communication

- Notify internal security, compliance, legal, and customer support teams.
- Follow regulatory and customer notification timelines based on jurisdiction and impact.
